# Roadmap

As tarefas abaixo são propostas, não recursos concluídos.
The tasks below are proposals, not completed features.

## Próxima entrega / Next release
- [ ] Publicar no GitHub Pages e registrar URL / Publish and record the live URL.
- [ ] Exportar configurações sanitizadas GTM Web e Server / Export sanitized configurations.
- [ ] Registrar capturas de validação sem dados pessoais / Add sanitized validation screenshots.
- [ ] Revalidar eventos e consentimento no domínio público / Revalidate on the public domain.

## Qualidade e mensuração / Quality and measurement
- [ ] Decidir se WhatsApp flutuante será mensurado / Decide whether to track the floating button.
- [ ] Definir parâmetro para idioma selecionado / Define selected-language measurement.
- [ ] Rever deduplicação por envio em vez de por página / Review submission-level deduplication.
- [ ] Automatizar regressão de consentimento e navegação / Automate consent and navigation regression.
- [ ] Auditar acessibilidade e desempenho / Audit accessibility and performance.

## Evolução para serviço real / Production evolution
- [ ] Backend de cadastro com persistência, validação e proteção contra abuso / Registration backend.
- [ ] Evento de sucesso condicionado à confirmação do backend / Backend-confirmed success event.
- [ ] Política de privacidade, retenção e gestão de fornecedores / Privacy, retention and vendor management.
- [ ] CMP e consentimento por categoria caso surjam novos fornecedores / Category-specific consent.
- [ ] APIs de mídia com credenciais no servidor e deduplicação / Media APIs with server-side credentials.
- [ ] URLs próprias por idioma e estratégia SEO, se necessário / Language URLs and SEO strategy.

## Critério de conclusão / Definition of done
Uma melhoria deve incluir comportamento esperado, implementação, teste positivo e negativo, atualização da documentação e evidência de publicação quando aplicável.
Each improvement needs expected behavior, implementation, positive and negative checks, updated documentation and deployment evidence when applicable.
